## 本轮姓名问题复现与验证

真实标签页 `Yinghui He (何映晖)` 已加载 73 篇、3,576 次引用，作者栏使用 `Y He`。旧版只按完整标题姓名精确匹配，导致角色全部漏识别。新实现拆分双语姓名、生成常见首字母缩写，并在侧栏逐项显示候选、已观察写法及出现篇数。反序形式默认不勾选；选择按主页保存。

从该页面摘录前 9 条真实作者列表作为固定回归样本，隔离 MV3 浏览器默认无手动别名时识别 9/9；只选第一作者并打开高亮筛选后为 4 篇、784 次引用，三列背景一致，CSV 恰好包含同 4 篇。此为 9 条摘录的结果，不是全主页统计。

新增合成冲突作者 `Yuhang He` 后，原 `Y He` 自动推断被撤回，候选标明冲突并暂停自动匹配；即便用户曾勾选该候选也不绕过冲突。恢复论文列表后逐篇确认，只恢复被确认的一篇；同一名单重复出现 `Y He / Y. He` 或多个目标别名时也不自动判定角色。关闭某候选、刷新后保留、重新开启后立即恢复已验证。390px 布局无新增横向溢出。

完全同名但实际身份不同且页面没有其他区分证据时，系统仍不能证明身份；候选区明确说明这一限制。共同一作、通讯作者仍须原文核实后手动确认。

## 复现

在扩展目录运行 `npm test`、`npm run check`，不需要安装依赖。

浏览器回归脚本为 `scripts/authors-qa.cjs`、`scripts/browser-qa.cjs`、`scripts/layout-qa.cjs`、`scripts/loading-qa.cjs` 和 `scripts/compat-check.cjs`，需另行提供 Playwright 与支持加载扩展的 Chromium：

- `PLAYWRIGHT_MODULE`：Playwright 模块目录；未设置时使用可解析的 `playwright` 包。
- `CHROME_EXECUTABLE`：支持扩展的 Chromium 可执行文件；未设置时用 Playwright 默认 Chromium。
- `SCHOLAR_QA_OUTPUT`：测试输出目录；默认系统临时目录下 `scholar-lens-qa`。脚本始终创建独立浏览器配置。
- 三扩展测试另需 `LEGACY_HIGHLIGHTER`、`LEGACY_VENUE_STATS` 指向原扩展目录；原扩展代码未随包分发。

执行 `npm run test:authors`、`npm run test:browser`、`npm run test:layout`、`npm run test:loading` 或 `npm run test:compat`。详细成功检查列表另存于 `validation-results.json`。

## 尚未验证

本轮成功读取了用户真实标签页的旧版状态和作者名单，随后浏览器控制连接中断，因此未宣称新版已在用户当前标签页完成线上端到端验证。新版验收在独立 MV3 浏览器中使用真实摘录及标注清楚的合成冲突样本。未核验所有国家域名或未来 Scholar DOM 变化；第三方公开期刊快照虽有结构校验与样本核验，也不保证全表没有源数据错误。
